# Third-party components

Everything in this repository that is *content* — every sprite, tile, level,
instrument, note, sound effect and page of printed matter — is generated by the
Python in `tools/` and is original to this project. Nothing was sampled,
traced, ripped or borrowed from another game.

The parts that are not ours are the engine and the toolchain. They are not
tracked here (`butano/` is a pinned clone, see the README), but their compiled
code is linked into `LuvsFrightNight.gba`, so they are credited here.

| Component | Author | Licence | How it is used |
|---|---|---|---|
| [Butano](https://github.com/GValiente/butano) | Gustavo Valiente | zlib | The GBA engine. Linked into the ROM. Its `common/` variable-width fonts are the ones the menus and cards draw with. |
| [Maxmod](https://maxmod.devkitpro.org/) | Mukunda Johnson | ISC | Plays the `.xm` modules. Reached through Butano, linked into the ROM. |
| [devkitARM / libgba](https://devkitpro.org/) | devkitPro | Mixed, see below | Compiler, C runtime and GBA startup code. |
| [libtonc](https://github.com/devkitPro/libtonc), agbabi, and the other small runtime pieces Butano links | various | zlib / MIT / ISC | Reached through Butano. |

Butano ships the full licence text for every one of these in `butano/licenses/`
once the engine is cloned. That directory is the authoritative list; the table
above names the ones this game actually links.

## Trademarks

"Game Boy Advance" and "GBA" are trademarks of Nintendo. This project is not
affiliated with, endorsed by, or licensed by Nintendo. Those names appear here
only to say, factually, which hardware the ROM runs on.

The cartridge header carries maker code `00` — unlicensed — because that is
what this is. devkitARM's `gbafix` writes Nintendo's `01` when it is called
without a maker code, and `tools/stamp_rom.py` corrects it after every build.
